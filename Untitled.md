   An enterprise-grade internal AI assistant enabling intelligent semantic search                    

  across organizational documents stored in SharePoint. Users query documents

  using natural language; the system retrieves semantically relevant content                        

  using vector search and generates grounded, context-aware responses via LLM.                      

  Built with a FastAPI backend, using LangChain for orchestration and both

  Pinecone (cloud) and FAISS (in-house) as vector stores.
